# Shlomi Hazan | Portfolio Website

A personal portfolio and resume website built with **HTML, CSS, and JavaScript**, hosted with **GitHub Pages**.

The website presents my background as a Computer Science student and software developer, including selected projects, technical skills, development tools, education, military service, pre-military leadership program, and contact links.

## Live Website

[Visit Portfolio](https://shlomi-hazan.github.io/)

## About

This portfolio was created as a clean, responsive, and bilingual personal website.  
It is designed to showcase my software development journey, academic background, practical projects, and leadership experience in a professional and accessible way.

## Features

- Responsive personal portfolio website
- Light and dark mode toggle
- English / Hebrew language toggle
- RTL support for Hebrew content
- Resume view and download buttons
- Separate English and Hebrew resume files
- Project showcase section
- Skills and development tools sections
- Education timeline
- Military service and pre-military leadership sections
- Contact buttons for Email, GitHub, and LinkedIn
- Hosted using GitHub Pages
